# កម្មវិធីបែងចែក និងគ្រប់គ្រងកាលវិភាគបង្រៀនគ្រូ
### School Timetable Decomposer & Teacher Schedule Management System
**ឆ្នាំសិក្សា ២០២៦ - ២០២៧ | ក្រសួងអប់រំ យុវជន និងកីឡា**

---

## 📌 ១. សេចក្តីផ្តើម
កម្មវិធីនេះត្រូវបានបង្កើតឡើងដើម្បីដោះស្រាយបញ្ហាប្រឈមក្នុងការបែងចែកម៉ោងបង្រៀនចេញពី **តារាងកាលវិភាគរួម (Master Timetable)** របស់សាលារៀន ទៅជា **កាលវិភាគផ្ទាល់ខ្លួនសម្រាប់លោកគ្រូ-អ្នកគ្រូម្នាក់ៗ** ដោយស្វ័យប្រវត្តិ មានភាពច្បាស់លាស់ ត្រឹមត្រូវ ១០០% គ្មានការជាន់ម៉ោងគ្នា ព្រមទាំងផ្តល់នូវប្រព័ន្ធគ្រប់គ្រង **គ្រូបន្ទុកថ្នាក់** និង **បញ្ជីឈ្មោះគ្រូមុខវិជ្ជា** យ៉ាងពេញលេញ។

---

## 🚀 ២. របៀបដំណើរការកម្មវិធី (Quick Start)

### វិធីទី១ ៖ ដំណើរការដោយស្វ័យប្រវត្តិតាមរយៈ Batch File (ងាយស្រួលបំផុត)
* គ្រាន់តែចុចពីរដង (Double Click) លើឯកសារ **`run_app.bat`**
* កម្មវិធីនឹងចាប់ផ្តើមដំណើរការ Server និងបើក Browser ទៅកាន់អាសយដ្ឋាន `http://localhost:5000` ដោយស្វ័យប្រវត្តិ។

### វិធីទី២ ៖ ដំណើរការតាម Command Line
```powershell
cd F:\Timeline
python app.py
```
បន្ទាប់មកបើកកម្មវិធីរុករក (Chrome, Edge, Firefox) រួចចូលទៅកាន់ ៖ `http://localhost:5000`

## 🌟 ៣. មុខងារចម្បងៗដែលបានបន្ថែម និងអភិវឌ្ឍន៍

### ១. 🎯 មុខងារកែនាមគ្រូបន្ទុកថ្នាក់ (Edit Homeroom Teacher Names)
* **កែប្រែដោយផ្ទាល់តាមថ្នាក់នីមួយៗ (Quick Edit in Class View)** ៖
  * នៅក្នុងទំព័រ «កាលវិភាគតាមថ្នាក់រៀន» មានប៊ូតុង **«✏️ កែនាមគ្រូបន្ទុកថ្នាក់»** នៅក្បែរឈ្មោះគ្រូបន្ទុកថ្នាក់។
  * លោកអ្នកអាចចុចដើម្បីវាយបញ្ចូលឈ្មោះថ្មីដោយផ្ទាល់ ឬជ្រើសរើសឈ្មោះគ្រូចេញពីបញ្ជីគ្រូមុខវិជ្ជា។
* **ផ្ទាំងគ្រប់គ្រងគ្រូបន្ទុកថ្នាក់សរុប (Homeroom Manager Tab)** ៖
  * មានទំព័រដាច់ដោយឡែក «🎯 កែនាមគ្រូបន្ទុកថ្នាក់» បង្ហាញថ្នាក់ទាំង ១៧ (១២A ដល់ ៧C)។
  * អាចកែប្រែឈ្មោះគ្រូបន្ទុកថ្នាក់ម្តងមួយៗ ឬកែប្រែទាំងអស់ រួចចុច **«💾 រក្សាទុកឈ្មោះគ្រូបន្ទុកថ្នាក់ទាំងអស់»**។
  * ឈ្មោះដែលបានកែប្រែ នឹងត្រូវធ្វើបច្ចុប្បន្នភាពដោយស្វ័យប្រវត្តិតាម ៖
    * តារាងកាលវិភាគរួម (ពេលព្រឹក និងពេលរសៀល)
    * កាលវិភាគប្រចាំថ្នាក់នីមួយៗ
    * បណ្ណកាលវិភាគគ្រូបង្រៀន
    * ឯកសារ Excel (.xlsx) ទាំងមូល!

### ២. 👥 បញ្ជីឈ្មោះគ្រូមុខវិជ្ជា (Subject Teachers Directory)
* បង្ហាញបញ្ជីឈ្មោះលោកគ្រូ-អ្នកគ្រូតាម **ក្រុមបច្ចេកទេស/មុខវិជ្ជាឯកទេស** ទាំង ១២ មុខវិជ្ជា។
* **ព័ត៌មានលម្អិតរបស់គ្រូម្នាក់ៗ** ៖
  * កូដបង្រៀន (ឧ. K1, M1, P1...)
  * គោត្តនាម និងនាមពិតប្រាកដ
  * ភេទ (ប្រុស / ស្រី)
  * មុខវិជ្ជាឯកទេស
  * បន្ទុកម៉ោងបង្រៀនសរុប (បំបែកជា ម៉ោងព្រឹក និងម៉ោងរសៀល)
  * គ្រូបន្ទុកថ្នាក់ (បញ្ជាក់ថ្នាក់ដែលគាត់ទទួលបន្ទុក)
  * លេខទូរស័ព្ទ និងកំណត់សម្គាល់
* **មុខងារបន្ថែមគ្រូមុខវិជ្ជាថ្មី (➕ Add Subject Teacher)** ៖
  * អាចបន្ថែមគ្រូបង្រៀនថ្មី ឬគ្រូកិច្ចសន្យា/គ្រូជំនួស ដោយកំណត់កូដ ឈ្មោះ ភេទ មុខវិជ្ជា លេខទូរស័ព្ទ និងបន្ទុកថ្នាក់។
* **មុខងារស្វែងរក និងច្រោះ (Search & Filter)** ៖
  * ស្វែងរកតាមឈ្មោះ កូដ លេខទូរស័ព្ទ ឬថ្នាក់បន្ទុក។
  * ច្រោះមើលតាមមុខវិជ្ជា (ខ្មែរ, គណិត, រូប, គីមី, ជីវ, ផែនដី, ប្រវត្តិ, ភូមិ, ពលរដ្ឋ, កីឡា, អង់គ្លេស, សេដ្ឋកិច្ច)។
* **បោះពុម្ពបញ្ជីឈ្មោះគ្រូ (🖨️ Print Subject Teachers Roster)** ៖
  * ទម្រង់បោះពុម្ព A4 ផ្លូវការ មានក្បាលលិខិតក្រសួងអប់រំ យុវជន និងកីឡា សម្រាប់តម្កល់នៅការិយាល័យសិក្សា។

### ៣. 👨‍🏫 កាលវិភាគគ្រូបង្រៀន (Individual Teacher Timetables)
* ជ្រើសរើសគ្រូម្នាក់ៗ ដើម្បីមើលកាលវិភាគផ្ទាល់ខ្លួនពេញមួយសប្ដាហ៍ (ព្រឹក និងរសៀល)។
* បង្ហាញម៉ោងបង្រៀនសរុប បញ្ជីថ្នាក់ត្រូវបង្រៀន និងថ្ងៃទំនេរ (Off-duty)។
* ប៊ូតុងបោះពុម្ពបណ្ណកាលវិភាគទោលភ្លាមៗ។

### ៤. 🏫 កាលវិភាគតាមថ្នាក់រៀន (Class Timetables)
* មើលកាលវិភាគសិស្សទាំង ១៧ ថ្នាក់ (១២A ដល់ ៧C) ព្រមទាំងបញ្ជីគ្រូបង្រៀនដែលត្រូវបង្រៀនថ្នាក់នោះ។
* ប៊ូតុងបោះពុម្ពកាលវិភាគថ្នាក់សម្រាប់បិទតាមបន្ទប់រៀន។

### ៥. 📋 តារាងម៉ោងរួម (Master Schedule View)
* បង្ហាញតារាងកាលវិភាគធំពេញលេញទាំងពេលព្រឹក និងពេលរសៀល។
* **Interactive Spotlight** ៖ ចុចលើកូដគ្រូណាមួយ វានឹង Highlight ម៉ោងបង្រៀនរបស់គ្រូនោះនៅគ្រប់ថ្នាក់ទូទាំងសាលា។

### ៦. 📊 ស្ថិតិ និងបន្ទុកម៉ោង (Workload Matrix)
* វិភាគបន្ទុកម៉ោងគ្រូទាំងអស់ធៀបនឹងស្តង់ដារក្រសួង (ពេញបន្ទុក $\ge 18$ ម៉ោង, មធ្យម $14-17$ ម៉ោង, ស្រាល $< 14$ ម៉ោង)។

### ៧. 🖨️ មជ្ឈមណ្ឌលបោះពុម្ព និងទាញយក (Print & Export Hub)
* បោះពុម្ពបណ្ណកាលវិភាគគ្រូទាំងអស់លើក្រដាស A4 មានក្បាលលិខិតផ្លូវការ និងកន្លែងចុះហត្ថលេខានាយកសាលា។
* បោះពុម្ពកាលវិភាគថ្នាក់ទាំងអស់។
* បោះពុម្ពបញ្ជីរាយនាមគ្រូមុខវិជ្ជា។
* ទាញយកឯកសារ Excel (.xlsx) ដែលមាន ៤ សន្លឹកការងារ (ព្រឹក, រសៀល, បន្ទុកម៉ោង, បញ្ជីឈ្មោះគ្រូមុខវិជ្ជា)។

## 📁 ៤. រចនាសម្ព័ន្ធឯកសារ (Project Structure)
```
F:\Timeline\
│
├── app.py                     # Flask Web Application Backend & API Endpoints
├── excel_exporter.py          # ម៉ូឌុលបង្កើតឯកសារ Excel ៤ សន្លឹកការងារ
├── run_app.bat                # ឯកសារចុចដំណើរការកម្មវិធីភ្លាមៗ (One-click Launcher)
├── README.md                  # ឯកសារណែនាំការប្រើប្រាស់
│
├── data/
│   ├── schedule_data.json     # ទិន្នន័យកាលវិភាគដើម (ព្រឹក, រសៀល, ថ្នាក់, មុខវិជ្ជា)
│   ├── custom_homeroom.json   # ទិន្នន័យកែសម្រួលឈ្មោះគ្រូបន្ទុកថ្នាក់
│   └── custom_teachers.json   # ទិន្នន័យឈ្មោះពិត ភេទ លេខទូរស័ព្ទ និងបន្ទុកថ្នាក់របស់គ្រូ
│
├── templates/
│   └── index.html             # ទំព័រមុខ Web Application (Tailwind CSS)
│
└── static/
    ├── css/
    │   └── styles.css         # រចនាបទខ្មែរ Google Fonts & Print Styling A4
    └── js/
        └── app.js             # Logic អន្តរកម្ម ស្វែងរក កែនាមគ្រូ បន្ថែមគ្រូ និងបោះពុម្ព
```
